Hard = dead address (invalid recipient / no such user) — real list-quality damage; suppress these. Block = the recipient gateway rejected us (spam/policy/reputation, e.g. Mimecast/Barracuda/Spamhaus) — a sender signal, NOT a bad address; fix with warmup, auth, and volume control, not suppression. Soft = temporary (mailbox full, greylist, rate) — retries handle it. Classification parses the SMTP reason in each bounce event (no stored type), validated at ~98% coverage. Bounce events are webhook-partial, so absolute counts are directional — the ratio of hard:block:soft is the reliable signal.
